## 一、一句话总结

## 四、关键演进主线（5 条）

1. **技术栈**：FastAPI → Flask 3.0（轻量、贴合原型期）→ 单一后端文件 src/app.py + 单页前端 index.html（i18n 双语）
2. **部署形态**：本地 Flask 直跑 → gunicorn+systemd 原生 → **Docker/podman 容器为默认形态**（蓝绿共享数据、18000 仅验收临时端口）
3. **工程体系**：手工部署 → 一键 deploy.sh（Python 3.12 三级获取 + 离线依赖回退）→ 三平台 CICD（Gitea 权威/GitHub 备份/GitLab 实验线隔离）
4. **质量**：35 项手工测试 → 400+ 项 TDD 全量回归 + 只读冒烟 11 项 + 性能门禁（800MB/100MB/并发）→ CI 计数基线防删减
5. **文档**：散落记录 → docs 体系单源化（PRD/ADR/测试/部署/复盘）+ README/AGENTS 双入口（人+AI）
