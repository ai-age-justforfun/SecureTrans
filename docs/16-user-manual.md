# SecureTrans 用户使用手册

> 版本：v2.7.x（跟随系统发布版本） | 2026-09-16 | 适用：公司内部研发环境
> 系统：SecureTrans 轻量级跨网文件审批摆渡系统（内网提交/审批 → 外网下载）
> 语言：界面支持中/英双语，右上角切换，默认中文
> 说明：本手册分"普通用户"与"管理员"两部分；普通用户看第 1-3 章与第 5-6 章，管理员另看第 4 章。

---

## 1. 系统简介

- **做什么**：把文件从内网安全摆渡到外网。内网用户提交并经过审批后，文件自动移到外网下载区，外网用户登录即可下载——全程不经过 U 盘/邮件，操作留痕可审计。
- **内外网边界**：
  - **内网**（公司内部网段）：全部功能可用（提交、审批、管理、下载）。
  - **外网**（办公网等非内部网段）：**仅允许登录 + 外网下载**，其余功能与菜单全部隐藏，管理接口一律 403。
- **访问地址**：内网 `http://<服务器地址>:8000`（外网同址，系统按来源 IP 网段自动识别内外网）。
- **浏览器**：现代浏览器（Chrome/Edge/Firefox）即可，无需安装任何客户端。

## 2. 账号与登录

| 项目 | 说明 |
|------|------|
| 账号来源 | AD 域账号（优先）或本地账号 |
| 登录格式 | 直接输入用户名（自动匹配本地/AD）；也可用 `域\用户名` 或 `用户名@域` 显式走 AD |
| 默认管理员 | `admin`，初始密码为部署时系统配置的重置密码（默认 `Init@123456`），首次登录后**建议立即修改** |
| 修改密码 | 本地用户可在系统内修改（**仅内网**）；**AD 用户不能在本系统修改密码**，请到 AD 域控制器修改 |
| 禁用账号 | 被管理员禁用的用户无法登录；admin 永久使能不可禁用 |

## 3. 普通用户使用

### 3.1 提交文件（仅内网）

**入口**：左侧菜单"文件提交"。

**操作步骤**：
1. 选择文件：支持多选文件 / 选择整个文件夹；**单文件上限默认 800MB，一次最多 18 个文件**（可在系统配置中调整，界面上显示的值与系统配置一致）。
2. 填写提交信息（字段按一般思维顺序排列）：
   - **接收类型**（第一项）：
     - **公司内部**：仅需填写接收人姓名，单位可空；
     - **合作方**：优先从已配置的合作方下拉选择（自动带出单位）；若无合适项，选"其他（自行填写）"，手工填写接收单位 + 姓名，提交后**自动加入合作方清单**；
     - **非合作方**：必填接收单位 + 接收人姓名，提交后**不加入**合作方清单，仅作为下载任务与日志记录。
   - **接收密级**：按需选择。
   - **接收人姓名 / 接收单位**（按接收类型必填规则）、**接收邮箱**（可选）。
3. 提交。系统自动计算文件 MD5，并按以下顺序处理：
   - **免审批判定**：若管理员开启了"免审批总开关"且**本次提交的所有文件都命中已启用的特征码规则** → 自动通过，立即进入外网下载区；
   - 否则进入**人工审批**流程。
4. 提交后可在"我的提交"中查看进度。

**取消/清空**：选错文件或填写有误时，点击"取消/清空"一键重置表单（未提交的临时文件由系统定时回收，无需手工清理）。**未点击提交就刷新/离开页面，本次选择会丢失**（系统为无状态设计，属正常行为）。

### 3.2 我的提交

- 查看自己提交的全部记录：状态（待审批 / 审批中 / 已通过 / 已拒绝 / 已归档）、审批进度、文件 MD5。
- 已通过的文件可在此**下载**（内网）。
- 提交记录不可删除（历史留痕，供审计）。

### 3.3 审批（被管理员配置为审批人后可见"待我审批"）

| 接收类型 | 审批层级 | 说明 |
|---------|---------|------|
| 公司内部 / 合作方 | 一级 | 一级通过即摆渡到外网 |
| 非合作方 | 二级 | 一级 → 二级，二级通过后摆渡 |
| 免审批命中 | 零级 | 自动通过，无审批记录 |

- 动作：**通过 / 拒绝**；拒绝后文件移入归档（rejected 状态）。
- **同人跨级自动跳过（仅非合作方）**：若一级审批人同时具备二级审批权限（如二级审批人被同时配置为一级），一级通过后自动跳过二级审批直接摆渡。
- 公司内部 / 合作方提交单**不会**产生二级审批记录（审批链干净）。

### 3.4 外网下载（外网面）

- 外网登录后仅显示"外网下载"菜单。
- **只能看到并下载自己提交且已通过审批的文件**，看不到他人文件。
- 下载时响应头携带 `X-File-MD5`，可用于本地校验文件完整性（上传 → 存储 → 下载 → 本地校验四方 MD5 一致）。
- 文件超过系统有效期会被**自动归档**（见第 5 章），归档后不可再下载。

## 4. 管理员使用（仅 admin，仅内网）

> 只有 `admin` 一个管理入口；普通用户默认无任何管理权限。**外网面对 admin 也只放行登录 + 下载**，所有管理操作必须从内网访问。

### 4.1 仪表盘
全局运营统计（今日提交 / 待审批 / 免审批率 / 文件总数等），仅 admin 可见。

### 4.2 所有提交记录
全部用户的提交单列表；点开单条记录可**查看附件并下载审查**（任意状态均可审，仅内网）；可删除提交单。

### 4.3 用户管理
- **本地用户**：创建（默认普通用户）、删除、重置密码、启用/禁用（**admin 永久使能，不可禁用**）。
- **AD 用户**：
  - **AD 配置**：在"AD 配置"页维护服务器 / 端口 / BaseDN / 域等参数（可从 .env 导入一次，后续保存在系统数据库）；可**测试连接**。
  - **AD 用户搜索**：按精确用户名搜索验证（如 `ldapsearch` 类似查询），确认用户存在后即可被配置为审批人。
  - AD 用户直接使用域账号登录，无需在系统内创建。

### 4.4 审批人配置
- 配置**一级审批人 / 二级审批人**（从本地用户 + AD 用户中选择），可删除。
- **无审批人时用户提交会失败并提示原因**（如"公司内部必须有一级审批人，非合作方必须有一级和二级审批人"），保证审批流程闭环。

### 4.5 合作方管理
- 增 / 改 / 删 / **启用/禁用**（禁用后不参与提交下拉与白名单判定）。
- **联系人为必填**，邮箱可选；名称去重（不区分大小写）。
- 用户在提交页"其他（自行填写）"自动加入的合作方，也会出现在此清单中，可在此全量编辑。

### 4.6 特征码管理（免审批规则）
- 内置规则模板（PDF / Word / 压缩包 / Vivado bitstream 等）**默认全部禁用**，管理员按需启用/停用。
- 可**新增自定义规则**：文件类别（扩展名）、文件名正则、二进制特征（文件头 hex）、组合规则（特征码 AND 后缀，更严格，推荐）。
- **安全兜底**：免审批总开关开启但没有任何启用的特征码规则 → 无文件可匹配 → 所有提交仍走人工审批（默认保守）。

### 4.7 系统配置
- **默认有效期（天）**：全局唯一设置点，默认 7 天；所有提交单统一使用该值（提交人无法自定）。
- **单文件上限（MB）**、**批量提交数量上限**：默认 800MB / 18 个，界面显示与配置一致。
- **免审批总开关**：默认关闭，管理员按业务手工开启。
- **重置密码**：部署/重置时把 admin 密码恢复为该系统配置值（默认 `Init@123456`）。
- 保存即生效（配置保存在系统数据库，跨版本保留）。

### 4.8 审计日志
- **明细 Tab**：按时间线逐条记录所有用户/管理员/系统关键动作（登录、提交、审批、下载、管理操作、超时归档等）。
- **统计 Tab**：默认近 30 天（可自定义起止日期），两张矩阵：
  - 按文件类型（人员 × 文件类型 × 总数，含合计）；
  - 按每日（人员 × 日期 × 操作数，含合计）。
- 统计口径（四维）：**提交文件数 / 审批次数 / 下载次数 / 管理操作**（普通用户无管理操作列）。

### 4.9 系统工具
- **备份 / 恢复**：**系统备份（仅数据库）与业务备份（仅文件数据）完全分离**，各自独立列表、独立恢复，互不混淆。
- **出厂重置**：恢复初始出厂状态（自动先备份，输入确认码 `RESET`）。
- **模拟数据**：仅测试环境生成模拟数据（输入确认码 `MOCK`）；生产环境不要使用。
- **清理过期**：手动触发超时归档 / 未提交临时文件清理。

### 4.10 修改密码
- admin 修改密码仅限内网；外网界面不显示修改密码入口。修改后如忘记，可在系统配置中重置。

## 5. 关键规则与数据

| 规则 | 说明 |
|------|------|
| 文件有效期 | 系统配置统一（默认 7 天）。**提交未审批**（从提交时间起算）与**审批通过未下载**（从审批时间起算）超时后自动归档（0 拷贝移动），审计记录 `system_archive_expired` |
| 未提交临时文件 | 上传未提交的临时文件保留 24 小时后由系统自动回收（直接删除，不归档、不写审计） |
| 免审批条件 | 免审批总开关开启 **且** 提交单所有文件命中已启用的特征码规则 → 自动通过 |
| 审批链 | 公司内部 / 合作方：一级；非合作方：一级 + 二级；同人跨级自动跳过（仅非合作方）；免审批 = 零级 |
| 内外网隔离 | 外网仅登录 + 下载；管理接口外网一律 403；本机回环地址（127.0.0.1）恒视为内网 |
| 文件完整性 | MD5 端到端四方一致：上传计算 → 数据库存储 → 下载响应头 → 下载内容本地校验 |
| 语言与时区 | 界面中英双语（业务数据不翻译）；时间统一显示服务器系统时区 |
| 并发规模 | 支持 3-5 人同时操作，峰值 50 注册用户（当前内部规模） |

## 6. 常见问题（FAQ）

| 问题 | 处理 |
|------|------|
| 登录失败 | 检查密码；确认账号未被禁用；AD 用户确认域控制器可达（联系管理员） |
| 外网访问报 403 | 外网只允许登录 + 下载；提交 / 审批 / 管理操作请从内网访问 |
| 忘记密码 | 本地用户：请 admin 在"用户管理"重置；AD 用户：到 AD 域控制器修改 |
| 无法下载文件 | 文件未通过审批 / 已超过有效期自动归档 / 不是本人提交的文件（只能下载自己的） |
| 提交提示"无审批人" | 联系 admin 配置对应层级审批人（公司内部/合作方需一级；非合作方需一级+二级） |
| 修改密码失败 | AD 用户需到域控修改；外网不支持修改密码（请用内网） |
| 界面上传后刷新文件没了 | 正常行为（无状态设计）：未提交即弃，临时文件由系统 24h 回收 |
